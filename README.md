# Asistente Alcaldia Cucuta

Proyecto base para desarrollar un asistente inteligente orientado a tramites estrella del sector de rentas e impuestos de la Alcaldia de San Jose de Cucuta.

## Modulos

- `frontend/`: aplicacion React para ciudadanos y panel administrativo.
- `backend/`: API en FastAPI y logica de integracion del asistente.

## Enfoque actual

Esta base queda preparada para cerrar la Iteracion 1 de XP:

- entorno organizado,
- estructura tecnica separada por frontend y backend,
- y archivos iniciales para comenzar a construir historias de usuario.
